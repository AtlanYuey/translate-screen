# AY Translate 1.5

本轮处理漏识别/漏译、请求参数、译文可读性和图片手势。用户实测识别 0.28 秒、翻译 17.47 秒，主要等待来自翻译阶段，不能简单归因于 OCR 或设备性能。

## 修改

- 原生文档识别后，只对竖排图中的未覆盖字形列做本机补查，最多六列；完整列不会重复识别，横排正文受到保护。成功读出完整列后才替换局部碎片，失败保留原文。不是无上限重复扫描，也不额外上传图片。
- AI 返回缺失区域，或将带平假名的完整日文句子原样作为中文结果时，最多补译相关区域一次，保留成功译文。缺失/重复/额外 ID 仍严格校验。
- 每个服务独立保存请求参数，默认不覆盖模型参数。提供 OpenAI reasoning_effort、DeepSeek thinking、Qwen enable_thinking 预设，以及带嵌套对象、数值和布尔类型的自定义 Body JSON。预览实际参数，测试翻译使用同一配置。不同模型支持情况以供应商为准；思考强度越高可能越慢。不允许覆盖消息、模型、流式输出、工具或密钥字段。
- 译文默认 semibold，增加对比色外描边，先描边再填字以保留极小字号的实心笔画；先画所有背景补丁再画所有译文，避免补丁擦除相邻译文。修补包含淡色抗锯齿边缘；透明补丁仅保留紧邻修复像素且颜色匹配的背景边缘，避免分别缩放原图与补丁时露出原字轮廓，同时不重画邻近原字。
- “显示 → 点击文字查看详情”默认关闭，可主动开启；关闭时文字不截获点击/长按，全文模式仍可使用。设置通过现有共享与 iCloud 设置桥同步。
- 结果页改用原生 UIScrollView：双指围绕手势中心缩放、惯性平移、边缘回弹、双击定位放大/还原。切换原图保留位置与倍率，底部上滑关闭仍保留。
- 品牌标志从原始 SVG 离线转换为 256px PNG，避免资产编译器对渐变与 em 单位解析不一致；无运行时网络图标请求。新桌面图标使用蓝色玻璃双气泡与交换符号。

## 验证

Linux 核心回归覆盖旧配置迁移、参数类型/覆盖/保护、真实 HTTP 请求 Body、单次补译、字形覆盖及淡色边缘恢复。macOS Actions 运行真实漏列补查、iOS 原生缩放焦点/配置/图标可见性、实际双指手势与共享界面回归，并构建带共享扩展的未签名 IPA。最终结果及下载链接在 PR 中记录。

聊天中的漫画未作为本地原图提供，合成日文图回归不能等同所有漫画都识别完整。补查和单次补译可能增加异常图片的耗时；不承诺任意模型一秒完成。自定义参数不受供应商支持时会返回其状态码，响应内容及密钥不会写入日志。桌面图标已在本地生成并打包；不创建 Release。
