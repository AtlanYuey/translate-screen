# 中文界面、轻量结果与多服务配置（1.1）

## 这次调整

- 界面默认简体中文，也可在“设置 → 界面 → 软件语言”选择繁体中文、English 或跟随系统。界面语言独立于 OCR 源语言和翻译目标语言，避免把 Chinese 等界面标签再交给 OCR 机器翻译。
- 完整结果页去掉导航栏、语言标题、底部对比选择器和字号滑条，截图延伸到屏幕边缘。只保留悬浮的更多、原图符号和叉号；复制、全文阅读、引擎切换、缩放重置和设置集中到更多菜单。
- 字号、默认结果模式和文字样式统一在设置调整。原图符号可随时对比；放大后的图片仍可平移，不把正常的全文滚动或缩放平移误当成关闭。
- 默认不再使用灰色材质文字块。对文字外围取样，使用主要背景色遮盖原字，并按亮度选择黑/白译文；没有变化的文字不重复覆盖。复杂渐变/照片纹理不属于图像修复，采样不能精确重建被原字挡住的像素。

## 快捷指令为何能留在原 App

参考用户提供的 iTranscreen 截图及其[公开产品说明](https://www.itranscreen.com/)，采用“先截图、再临时查看、结束后继续原来的操作”的交互。没有反编译该 App，也不声称知道其内部实现。

默认“翻译截图”改为后台 App Intent，返回 Apple 的互动系统片段 `SnippetIntent`，不将主 App 切到前台，不再返回 `ProvidesDialog` 或“Opening your translated screen…”对话。结果保存在内存里，原图切换通过互动片段按钮完成，关闭清理当前结果。系统负责片段的呈现、收起和手势；结束预览时，原来使用的 App 仍在背后。

这与“把主 App 打开，再强制退出或跳回任意来源 App”不同：后者没有通用的公开 iOS API。本实现不使用 `suspend`、`exit(0)` 或私有 SpringBoard 接口，也不是任意 App 上方的全屏透明窗口。系统可能显示自己的快捷指令进度或片段外框，App 无法承诺把系统 UI 一并隐藏。

系统片段的尺寸、滚动和底部手势由 iOS 决定，必须真机验证。片段里只有轻量原图/译图显示；需要双指缩放、平移、复制或详细操作时，点更多符号进入完整 App，直接接续同一处理状态，不重复上传或识别。App 内结果也支持从靠近底部的图片区域上滑关闭；真正系统 Home 手势由 iOS 接管，App 内关闭本身不能保证切回别的 App。

### 苹果语言包与云端许可

后台片段只用已安装的 Apple 翻译语言模型。首次缺少语言包时，片段提示进入 App，通过系统 `translationTask` 下载/确认；之后即可不切换主 App 使用本地预览。自动检测源语言在本地完成。慢请求可在 App 接续，避免后台时间限制导致重复计费。

AI 首次访问所选地址和模型前，片段同样要求许可；不同服务有各自许可，OCR 和翻译分别授权。不调用 AI 时不读取 API Key。片段重新绘制只读取缓存，不重新发起 OCR/翻译或收费请求。新截图替换旧结果，过期 token 不能访问或关闭新截图；结果仅保留于内存，并设定最长十分钟缓存期限。

如系统仍缓存旧动作呈现方式，更新 App 后运行一次主 App，重新选择快捷指令的第二步“翻译截图”。若需要原有直接打开方式，使用新增的“在 App 中翻译截图”；两种动作都没有自定义完成提示。

## 多个 AI 服务

在“设置 → AI 服务 → 添加 AI 服务”选择预设，填写自定义名称、Base URL、模型和可选 API Key。可保存同一服务商的多个配置，例如“DeepSeek 日常”“DeepSeek 高质量”“Gemini 图像识别”，分别保留密钥和模型。

预设依次包含 DeepSeek、Gemini、OpenAI、通义千问、硅基流动、Kimi、智谱、OpenRouter，最后固定为“OpenAI（其他）”作为自建或其他兼容接口的兜底。预设使用服务商的 OpenAI 兼容地址；模型名称和地址仍可修改，不假定某个特定模型永远可用。Gemini 使用其官方 OpenAI 兼容通道，而不是向原生 generateContent 地址发送错误格式。

DeepSeek 预设默认仅用于文字翻译；OCR 只显示已开启图像输入的配置。用户仍须选择实际具备图像能力的模型，不能靠勾选开关让文字模型支持图片。

OCR 和翻译各自选择当前服务，点一次即可切换，其他服务不被覆盖或删除。每项服务使用独立 UUID 对应的 Keychain 条目；重命名不丢 Key，更换地址清除该项旧 Key，删除一项也不影响其他服务。原有两个单配置会迁移到服务列表，旧密钥成功写入新条目后才删除；设备锁定导致失败时可以继续迁移。

## 验证范围

新增核心测试覆盖多项保存/恢复、独立选用、删除、视觉能力约束、许可身份、语言自动匹配与外围颜色采样。新增 iOS 宿主测试覆盖中文资源、旧配置/Keychain 迁移、多服务密钥保留、截图上下坐标采色、片段接续与过期 token 隔离，并生成中文结果页、设置页和服务页截图附件。

macOS CI 编译真实的 App Intents/Translation/SwiftUI 代码并运行测试。仍需真机验收：系统片段实际大小、底部上滑返回来源 App、首次语言包准备、Shortcuts 动作升级、复杂图片底色效果及供应商真实模型调用。不能把 Simulator 的单元测试视为已经验证这些系统交互。
