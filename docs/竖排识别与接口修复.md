# 1.3：竖排识别、原图保留和多服务同步

本轮针对用户提供的日文竖排漫画、大小字体照片、快捷指令界面和 Feather 自签截图修改现有工程。默认仍为 Vision + Apple Translation，未添加账号、广告或默认云端上传。

## 原因与修改

- **小字漏识别**：Vision 默认 `minimumTextHeight` 为图片高度的 1/32。改为 0.0025，高分辨率小字使用有限的重叠分块识别，结果映射回同一张正向原图，并去重。截图方向先统一，避免 EXIF 方向与裁切坐标不一致。
- **竖排巨大单字**：过去按竖排整列的高度推算字号，又截断到原框内。现在区分横排与竖排，保存原始字高/列宽；日文竖排通过本地字符框将正立字形重排为水平条带再识别，并恢复原坐标。真实回归发现 Vision 的字符检测器对干净竖排也可能零结果，因此增加受亮暗背景约束的本地字形连通区域定位：从较大的笔画推算列与行距，将分离笔画和浊点合回同一格，再交给 Vision 识别。低对比图案不作为这条备用路径的可靠位置。相邻竖排列按从右到左组成上下文；不能跨越较大的间距或完全不同的高度区域。
- **覆盖不可读**：竖排中日韩译文按从上到下、从右到左排版，以原字列宽估算字号；水平文字继续按实际字体行高和原字高估算。用户百分比在各区域的自动字号基础上乘算。译文只有完整放得下才覆盖，不能放下时保留原图，仍可点击区域阅读全文；不再绘制巨大的首字或省略号来遮挡原文。界面和导出图片共用绘制函数。
- **失败只剩黑页**：OCR/翻译失败时保留并显示截图，详情和重试放在可点开的提示中。已得到的译文保留，其他区域保留原文。Apple 翻译跳过能高置信确认已是目标语言的片段，以及纯数字/符号；整屏已是目标语言时不再创建无效的同语言翻译会话。自动模式先在本地确定剩余文字的源语言，将实际语言纳入会话缓存键，再调用系统模型准备；未知源语言不调用会报错的 `prepareTranslation()`。首次下载/许可由系统界面处理，仍需真机验收。

## Feather、自签与配置同步

主 App 与 `.appex` 仍声明共同的 App Group 和 Keychain 组，实际可用权限取决于证书描述文件及 Feather 的重签设置，源码不能替签名工具授予权限。

1. 能共享 App Group 时沿用原配置库；另将非敏感配置镜像到共享 Keychain，支持只保留 Keychain 共享权限的安装。每个服务的 API Key 仍单独存于 Keychain。此备用路径同步配置和密钥，不经 Keychain 传递历史截图；跨进程历史仍需要 App Group。
2. 更新后先打开一次主 App，再使用快捷指令。扩展加载前及设置中的“刷新共享配置”会读取最新服务、选中模型、语言和显示设置，也会同步删除服务及撤销许可。
3. 如果 Feather 同时移除两种共享权限，自动访问另一进程的私有库是不可能的。在主 App 的设置点击“复制配置与 API 密钥（本机 60 秒）”，打开翻译界面的设置并点“粘贴”导入。按钮明确告知包含密钥；只写入本机剪贴板，60 秒过期，不使用通用剪贴板或文件/服务器传递。导入的密钥进入该进程 Keychain，不进入 UserDefaults、历史或日志；云端上传许可不随导入授予。

自动路径有两个独立 UserDefaults 套件、同一 Keychain 替身的集成回归（配置桥接生产代码已在 Linux 运行）；全权限移除的路径有两个独立凭据库的导入、密钥不落偏好设置、过期拒绝及不自动授权回归。Feather 和购买证书的真机安装仍须用户验收，模拟器不能证明重签后权限保留情况。

## AI 接口编辑

- 所有输入均使用普通键盘；API Key 明文显示并载入已保存值，方便核对粘贴。修改接口时清除已载入的旧密钥，避免自动把旧凭据发往新地址。
- 粘贴密钥后延迟获取模型列表，亦可手动刷新。使用配置地址下的 `GET /models`，保持供应商路径前缀；支持常见 OpenAI 兼容模型列表。网络错误、权限不足或供应商未提供列表时，可选“其他模型”手填。
- 至少六段非目标语言的测试短句可选，包含日语、韩语、西班牙语等。点击测试使用当前未保存的地址、密钥、模型和目标语言，走生产翻译客户端。只发送测试句，不上传截图；保存不发起翻译调用。
- 核对 [DeepSeek 官方消息结构](https://api-docs.deepseek.com/api/create-chat-completion)后，修正 `system.content` 被编码为数组的问题：系统消息与纯文本用户消息现在使用字符串，只有带图像的用户消息保留内容数组。严格按该结构校验的供应商可拒绝旧请求；回归同时检查翻译字符串、上下文批次和视觉请求的图像数组，不调用私人付费账户。
- 请求仍为 HTTPS，拒绝跳转、限制响应大小，只显示清理后的错误，不显示服务商返回体或记录密钥。没有测试用户的私人供应商账户或付费额度。

## 轻量交互与设备尺寸

原图图标与叉号合成一个紧凑的原生 Liquid Glass 胶囊；单个图标保留 44pt 点击区域，视觉上不再是三个独立的大圆。点击原图图标切换，长按打开复制、全文、引擎和设置。显示选项留在设置，译图不新增顶部/底部工具栏。保留底部上滑结束扩展及双指缩放、拖动。

iPhone 开放横竖屏，iPad 保留全部方向；首页内容限制合理阅读宽度，译图按可用窗口重算并约束缩放/平移，覆盖 320pt 窄窗、iPad 竖屏、横屏、分屏尺寸。CI 增加独立 iPad Simulator 横竖屏 UI 检查。识别核心抽为同一份 `VisionTextRecognizer`，另在 macOS 15 Intel / Xcode 26.3 执行真实小字、竖排日文和横排保护回归，避免 OCR 测试完全依赖 macOS 26 的分配。未知或未提供具体型号的“iPhone Duo”、未来双屏/折叠硬件不能据此宣称已经真机测试。
