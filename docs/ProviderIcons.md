# 服务商品牌图标

来自 [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/ea434b96e75813517b377825e01c0df61dee8836) 的服务商品牌矢量图标；按随附 MIT 许可分发，商标归各自公司所有。不暗示官方合作。全部打包在本机，运行时不请求外部图标服务器。自定义服务保留通用接口图标。

1.5 使用 Inkscape 将来源 SVG 离线转换为 256×256 透明 PNG，避免 iOS 资产编译对渐变/相对尺寸的差异。原始矢量保留在 `provider-icon-sources/`，许可证与归属不变。
