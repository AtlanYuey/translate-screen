# AY Translate 1.7

本轮处理边缘动画四角裁切、选中文却输出英文、竖排遗漏、处理中断以及截图后黑屏闪烁。

- 边缘动画改为向视口内收的连续圆角路径；多层细线直接绘制，不使用越界阴影或每帧全屏模糊。保留减少动态效果支持。
- 首次 AI 请求同时限定目标语言名称和代码。高级参数不得覆盖语言、提示词或消息。明显偏离中文目标的英文句子直接报告失败并保留原图，不再自动补译错语种。缺失或未翻译区域仍允许一次覆盖补查；第三方模型遵从指令并非应用可以绝对保证。
- 竖排覆盖检查依据实际字形，而非整行外接矩形。遗漏列按四列拼成一张小图识别，最多检查十二列，避免逐列启动请求。保留置信度、几何及去重检查，不新增云端图片上传。
- 共享扩展在创建视图时开始读取图片，读取完成前背景透明；原图一直显示到译文和背景准备完成，消除应用自身的提前黑底。系统宿主的转场由 iOS 决定，需在实际快捷指令和来源 App 中复测。
- 背景修补延后到 OCR 与翻译完成后执行；复用原图存储，只缩小需要修补的区域。单块临时图约限 39 万像素，累计修补图限 400 万像素；超出预算保留原背景并绘制描边译文，避免继续扩大内存峰值。
- 活跃请求收到取消错误时保留原图并给出重试入口。增加“设置 → 处理诊断”：记录阶段、选定语言、内存警告次数与结束状态，最多各保留八条主 App/扩展记录。不记录截图、文字、API 地址、模型、密钥或响应，不同步到 iCloud。
- 底部上滑关闭按真实触摸起点判断，避免快速滑动越过底部区域后失效；处理中及图片放大时禁用关闭手势。共享扩展交互测试等待译图和背景均准备完成后，再验证缩放、切换原图与两种关闭方式。

核心回归覆盖首次请求语言限制与禁止错语种重试。原生回归覆盖横竖屏边框像素、透明等待画面、八个独立竖排气泡、背景修补、取消恢复及共享扩展交互。构建与实际结果见 PR。

没有真机崩溃或 Jetsam 日志，不能将未完成记录直接归因为内存终止，也不能宣称所有自动退出均已解决。再次发生时可复制处理记录定位中断阶段；系统直接终止扩展的情况无法由应用内部捕获最终原因。
